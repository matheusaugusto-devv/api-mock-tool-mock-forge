Bearer Token Flow

When active, generate a 5-minute bearer token by calling the auto-generated authentication endpoint: 

curl -X POST http://localhost:8000/api/{{ project.slug }}/auth \
  -H "Content-Type: application/json" \
  -d '{"apiKey": "YOUR_API_KEY_WITH_AUTH_SCOPE"}'

Include the returned token in subsequent requests header: Authorization: Bearer <access_token>.
